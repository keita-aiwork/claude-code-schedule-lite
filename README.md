# Claude Code の予定作業で定期実行する、予定表テンプレート（軽い版）

予定表（`queue.md`）に1行書くと、決まった時刻に Claude Code が手順書どおりに動き、結果の欄に「済」か「止めた理由」が残ります。
Claude デスクトップアプリの予定作業（ルーティンの Local）で Claude Code を毎時起こし、予定表の行を拾わせる、最小のスケジュール用テンプレートです。
中身は予定表・手順書1本・係の依頼文・CLAUDE.md だけ。どれも Markdown なので、プログラムを入れずに使えます。

```
| ID               | 予定             | 種類   | 対象 | 中身 | 状態 | 結果                                          |
| TEST-20261005-01 | 2026-10-05 07:03 | テスト | -    | -    | 済   | 07:04 読めた／CLAUDE.md の1行目OK／表の行 1 |
```

（上は書き方の例です。係が1行終えると、状態と結果の欄がこう書き換わります）

## 中身

| ファイル | 何をする物か |
|---|---|
| `queue.md` | 予定表。決まりと、テストの行の例が1つ |
| `playbooks/テスト.md` | 試運転の手順書。何も送らず、読めたかだけを結果に書く |
| `prompts/予定の係.md` | 毎時起きる「予定の係」の依頼文。予定作業に登録する |
| `CLAUDE.md` | このフォルダの決まり。Claude Code が毎回最初に読む |
| `LICENSE` | MIT ライセンス |

## 使うのに必要な物

- Claude の有料プラン（Pro・Max・Team・Enterprise のどれか）。デスクトップアプリで Claude Code を使うには有料プランが要ります（公式 desktop-quickstart）。Pro は月払いで $20/月・税別（2026-10-01 の公式の料金ページ）
- Claude のデスクトップアプリ（Windows・Mac）https://claude.com/download
- 予定の時刻に、PC とアプリが開いていて、PC が起きていること
- このリポジトリ自体は無料です（MIT ライセンス）

## 使い方（5段）

1. **置く**：このページの「Code」→「Download ZIP」で取って展開し、好きな場所に置く（例：デスクトップの「AI予定表」）。デスクトップアプリの Code タブで、このフォルダを開く。
2. **係を登録する**：Claude Code に「`prompts/予定の係.md` を読んで、`<フォルダ>` をこのフォルダの場所に置き換えてから、毎時55分ごろに起きる予定作業（Local）として登録して」と頼む。頼めない時は、左の一覧の「Routines」→「New routine」→「Local」で、指示の欄に中身を貼り、作業フォルダにこのフォルダを選ぶ。
3. **テストの行を入れる**：`queue.md` のテストの行の予定を、今から3〜5分後の時刻に書き換える（Claude Code に頼んでもよい）。
4. **1回動かす**：Routines の画面で予定の係を開き、「Run now（今すぐ実行）」を押す。最初の1回は「このワークスペースを信頼しますか？」や許可の画面が出ることがあります。内容を読んで、自分で選んでください。
5. **確かめる**：数分後に `queue.md` を開き、テストの行が「済」になって、結果の欄に時刻と一言が入っていれば完成です。あとは `playbooks/` に手順書を足し、予定表に行を書いていきます。

## ローカルの予定作業と、公式のクラウドのルーティンの違い

- このリポジトリ：デスクトップアプリの予定作業（Local）を使います。PC とアプリが開いていて、PC が起きている間だけ動き、作業フォルダのファイルをそのまま読み書きします（スリープ中の時刻は飛ばされ、次に開いた時に直近の1回だけが追いつきます。公式 desktop-scheduled-tasks）。
- 公式のクラウドのルーティン：PC を閉じていても動きますが、GitHub のリポジトリが前提です（2026年10月時点はリサーチプレビュー）。

## 止まりやすい所3つ

1. **許可の画面で待つ**：係は別の会話で動くので、許可の画面が出ると、そこで止まったまま待ちます。「常に許可」は、命令の文字が全部同じ時だけ効きました（2026-10-02、Windows の実機）。最初の1回は PC の前で Run now を押し、出た画面を見てください。手順書のコマンドは、1回に1つ・`;` や `&&` でつながない形にしてあります。
2. **「ずらし」で起きる時刻がずれる**：予定作業には、係ごとに決まった数分の遅れが足されます（公式）。実機では約14分ずれた係があり、55分に作ると次の時の09分ごろに起きました（2026-10-02、Windows）。登録した後に、Claude Code に「予定の係が実際に何分に起きるか確かめて、55分ごろになるよう合わせて」と頼んでください。
3. **前で長く待つ sleep は止められる**：予定より早く起きた時の待ちは、裏で動かす形（run_in_background など）で1回だけにしてあります。前で長く待たせると、止められることがありました（2026-10-02 の実機）。
